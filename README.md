# REX Ytdlp

A headless companion add-on for [REX Player](https://github.com/mpvRex/mpvRex).

## Overview

REX Ytdlp provides the embedded Python runtime, yt-dlp extractor, and QuickJS challenge solver to enable seamless web stream playback directly inside REX Player.

- **Headless Companion**: Runs as an isolated background AIDL service with no launcher icon.
- **Embedded Python 3.13 & QuickJS**: Resolves video/audio streams and extraction tokens locally on-device.
- **Designed for REX Player**: Communicates directly with the host player over fast Android IPC.
